# Actividad 6 · Catálogo interactivo con JavaScript

## Objetivo

Completar una aplicación de catálogo utilizando **JavaScript, arrays de objetos, métodos de arrays, DOM y eventos**.

Durante la actividad deberás trabajar únicamente en las secciones indicadas con `COMPLETAR` dentro de `js/app.js`.

## Archivos principales

- `index.html` → estructura de la página.
- `js/app.js` → datos, funciones y eventos de JavaScript.
- `ejercicio-1.md` a `ejercicio-5.md` → ejemplos de referencia para cada ejercicio.

## Actividades

1. Mostrar información de los productos dinámicamente.
2. Filtrar productos disponibles.
3. Filtrar productos por categoría.
4. Obtener una cantidad determinada de elementos.
5. Buscar productos por nombre.

## Importante

Los ejemplos incluidos en los archivos `.md` utilizan **otros contextos y datos**. Su objetivo es mostrar cómo funcionan las herramientas necesarias, pero no contienen la solución directa de los ejercicios.

La entrega deberá conservar la estructura original del proyecto y completar únicamente las partes solicitadas.
